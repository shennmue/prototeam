A tiny map maker project made in C 

# Usage  

(Check out the official [Raylib](https://github.com/raysan5/raylib/wiki/Working-on-GNU-Linux) installation guide for quick, step-by-step instructions tailored to your OS.)

To make your map, edit **map_one** file. 
Just draw your map using theses rules : 

- H : House
- R : Road 
- G : Ground

Example : 
```
GGGGGGG
GGGHGGG
GGGRRRR
GGGGGGG
```
